# Custody Note — releases

This repository hosts the public installers and auto-update feeds for
[Custody Note](https://custodynote.com), the police station attendance note app
for criminal defence practitioners in England and Wales.

It contains **no source code**. Each GitHub Release carries:

- Windows: `Custody-Note-Setup-<version>.exe` (+ `.blockmap`) and the `latest.yml` update feed
- macOS (signed and notarised): `Custody-Note-<version>-arm64|x64.dmg` / `.zip` and the `latest-mac.yml` update feed
- Microsoft Store package (`.msix`) where applicable

Download the latest version from **https://custodynote.com/download**.
Release notes: **https://custodynote.com/changelog**.

Published by Defence Legal Services Limited. To report a security issue, please
use the contact details at https://custodynote.com/contact — do not open a
public issue containing client data.
